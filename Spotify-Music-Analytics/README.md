# Spotify Analytics Dashboard | Tableau

An interactive Tableau dashboard developed to analyse Spotify music data and uncover insights into music popularity, artist performance, genre trends, and audio characteristics through data visualisation.

---

## Project Overview

This project explores Spotify music data using Tableau to identify patterns in track popularity, artist performance, genre preferences, and music characteristics.

The dashboard enables users to interactively explore music trends and compare artists, genres, and track features through visual analytics.

---

## Dashboard Features

### Key Performance Indicators (KPIs)

- Total Tracks: 32,833
- Total Artists: 10,693
- Average Popularity: 42.5
- Average Duration: 3.763 minutes

### Visualisations Included

- Popularity by Genre
- Top 10 Artists by Popularity
- Music Popularity Over the Years
- Danceability vs Energy Analysis
- Genre-Based Filtering
- Artist Performance Comparison

---

## Key Analytical Areas

### Genre Popularity Analysis

Examines average track popularity across different music genres, including EDM, Pop, Latin, R&B, and Rap.

### Artist Performance Analysis

Identifies the most popular artists in the dataset based on average track popularity.

### Music Trend Analysis

Explores changes in music popularity over time using album release years.

### Audio Feature Analysis

Investigates the relationship between danceability and energy levels to understand track characteristics.

### Interactive Data Exploration

Provides filters that allow users to explore the dataset by genre and compare different music categories.
